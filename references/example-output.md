# 範例成品

新寫的輸出要跟這裡同一個形狀：一句一行、意群空行、引用與判定分開、細線隔判定、粗線隔大段落、最後一定有完整版。

**這兩則輸入是為了示範而寫的，不是任何真實貼文。** 判定與替代寫法的做法照實，人跟事都是虛構的。

---

## 範例一：低頻內容（示範「先承接再講代價」與「可以直接換」）

輸入（虛構的一則公開抱怨貼文）：

```
我本來不想再講這種事
但這半年一直遇到同一種人
表面上說支持
轉頭就在群組裡講你壞話
這種人真的很噁心
```

輸出：

```
這篇的核心不是單純的憤怒。

比較像是：
我受夠了某一種互動方式，
所以我要講出來，把界線劃清楚。

━━━━━━━━━━
逐段
━━━━━━━━━━

「我本來不想再講這種事」
「但這半年一直遇到同一種人」

約 200 勇氣。

主詞在自己身上，
講的是自己的狀態跟自己的選擇。
這是整篇最站得住的地方。

──────────

「表面上說支持」
「轉頭就在群組裡講你壞話」

約 150 憤怒，但這是全篇離事實最近的一段，
講的是具體行為，不是人格。

先講一件事：
150 不是壞的一格。
它代表一個人已經不願意再吞忍，
比無力跟恐懼更有行動力。

可以直接換：
當面說支持、私下講另一套，
這種合作方式我現在會先停一下。

──────────

「這種人真的很噁心」

約 150 憤怒，全篇最低的一句。

真正把它拉低的不是設界線，
是把行為進一步等同於對人的定性。

可以直接換：
我沒辦法跟當面一套、背後一套的人合作。

──────────

曲線：
開頭 200 → 中段 150 → 結尾 150。

讀者帶走的是最後那一格，
所以整篇的餘味是厭惡，
不是那條界線。

━━━━━━━━━━
完整版（可以直接複製）
━━━━━━━━━━

我本來不想再講這種事，
但這半年一直遇到同一種情況。

當面說支持、私下講另一套，
這種合作方式我現在會先停一下。

我沒辦法跟當面一套、背後一套的人合作，
所以我會直接把距離拉開。

這是我替自己設的界線。

━━━━━━━━━━

這個版本保留了立場跟強度，
沒有原諒誰，也沒有叫自己放下、感恩。
換掉的只有位置：
從「你是什麼樣的人」
移到「我看到什麼、我決定怎麼做」。

整體落在 350 接納附近。
```

如果這類貼文的互動很高，要如實講，不要替使用者選：

```
互動高跟它落在 150、175 是同一件事。

憤怒跟比較會讓人想按、想留言，
這是它有效的原因。

代價是讀完的人會防衛，
也分不出自己會不會是下一個被寫的。

所以這不是對錯題，是選擇題。
```

## 範例二：整篇本來就在 200 以上（示範「不要製造修改」）

輸入（虛構的一則自我覺察貼文）：

```
昨天被問到一個問題
我把自己排在第幾順位
工作、家人…
我發現名單裡沒有我自己
我想不是因為我不在乎自己
是因為以前的我已經很任性了
現在我比較想的是怎麼把力氣用在別人身上
```

輸出：

```
這篇整篇在 200 以上，
所以我的工作不是升頻，
是把它好在哪裡講清楚，
再指出唯一一個值得覺察的地方。

━━━━━━━━━━
逐段
━━━━━━━━━━

「昨天被問到一個問題」
「我把自己排在第幾順位」

約 250 中立。

把問題原樣放著，
沒有先替自己辯護，也沒有先下結論。

──────────

「我發現名單裡沒有我自己」
「我想不是因為我不在乎自己」

約 250 到 350 之間。

前一句是 350 接納：
看見現況，而且沒有轉成自責。

後一句往回收了一點，
它在向外解釋，
像先擋住別人可能有的評價。

可以直接換：
名單裡沒有我自己。
這件事我先看著，不急著解釋。

──────────

「現在我比較想的是
怎麼把力氣用在別人身上」

約 310 主動加 500 愛。

從「我有」接到「我想給出去」，
而且是自己先動，不等條件齊備。

━━━━━━━━━━
唯一值得再看一眼的
━━━━━━━━━━

「以前的我已經很任性了」
這個歸因很溫柔，也很真。

只是如果它變成長期的理由，
「現在的名單裡沒有自己」
就不會再被檢視了。

一個可以自己問的問題：
現在的我，
想留多少給自己？

━━━━━━━━━━
完整版（可以直接複製）
━━━━━━━━━━

昨天被問到一個問題
我把自己排在第幾順位

工作、家人…
我發現名單裡沒有我自己
這件事我先看著，不急著解釋

以前的我已經很任性了
現在我比較想的是
怎麼把力氣用在別人身上
也想留一點給自己

━━━━━━━━━━

這篇只動兩個地方：
解釋那句拿掉，
結尾補一句留給自己。

其他一個字沒改，
因為它本來就在 350 以上，
改多了會把作者的聲音改掉。
```

## 從這兩份可以看出來的三件事

1. 判定藏在話裡面，不是表格。每一格都先講狀態，再講判準（拿掉對照組還站不站得住）。
2. 低頻先承接再講代價；高頻先講好在哪，只留一個提問。
3. 完整版永遠是最後一塊，乾淨到可以整段複製，底下才補「保留了什麼」與「動了哪幾處」。
