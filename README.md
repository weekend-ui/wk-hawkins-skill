# 霍金斯能量頻率檢查師（wk-hawkins）

一支給 Claude Code 用的 skill：把一段文字逐句或逐段對照霍金斯能量層級，指出它落在哪一格、那一格代表什麼意識狀態，然後給一句可以直接換上去的話。

定位是**鏡子，不是裁判**。它不判斷對錯，也不評論人品，只講句子。

設計：週末哥（WeKen AI）。

## 它適合用在哪裡

社群貼文、跟夥伴的對話、給主管或團隊的訊息、要發給客戶的信、寫給自己的東西。
這些內容的目的是被理解跟被信任，所以「這句話從哪裡講出來的」會直接影響效果。

**不適合拿來洗轉換導向的廣告文案。** 高頻的文案不等於高轉換的文案：廣告靠痛點驅動，而痛點在這張表上就是恐懼 100 跟慾望 125。硬升頻會把轉換一起洗掉。廣告只有一個反過來的用法，寫在 SKILL.md 的「反向模式」。

## 怎麼裝

Claude Code 的 skill 放在 `~/.claude/skills/`（專案內則是 `.claude/skills/`）。

```bash
git clone https://github.com/weekend-ui/wk-hawkins-skill.git ~/.claude/skills/wk-hawkins
```

或者直接把這個資料夾複製過去，確認長這樣：

```
~/.claude/skills/wk-hawkins/
├── SKILL.md
└── references/
    ├── original-prompt.md   本體規格，衝突時以它為準
    ├── scale.md             層級表，判定數值的唯一參照
    └── example-output.md    範例成品，決定輸出的形狀
```

## 怎麼叫

在對話裡說觸發詞，然後把要看的文字貼上去：

- 霍金斯頻率覺察師
- 霍金斯能量頻率檢查師
- 頻率覺察
- 看一下這段的頻率
- 這段話幾頻

它只在被叫的時候跑，不會自動接進你的寫作流程。

## 它會交出什麼

1. 一句定調：這張表是語言與意識的覺察框架，不是可客觀測量的頻率
2. 這篇文字的核心動線（它在做什麼）
3. 逐句或逐段的判定：數值區間加名稱，以及一句話講那一格的狀態
4. 低頻段落先承接再講代價，後面接一句「可以直接換：」
5. **完整版**：把所有建議照原文順序接起來，乾淨到可以整段複製貼上
6. 一句轉念提醒，以及「要不要出 200、350、400、540 四個版本對照」

整篇本來就在 200 以上的時候，它不會為了交東西而製造修改，只會講好在哪、留一個提問，完整版只做最小改動。

## 兩個要先知道的事

**這張表不是測量。** 數字來自肌肉測試（應用肌動學）。2013 年的雙盲隨機研究結果與隨機猜無異。所以這支工具永遠寫「落在 X 那一格」，不寫「頻率是 X」。它的價值是一套語言分類法，讓人講得出「這句話是從恐懼講的，還是從接納講的」。

**它不是心理諮商，也不是醫療建議。** 它處理的是文字，不是人。
